# React + Vite

My portfolio website is a well-designed and interactive platform that showcases my skills, projects, and experiences. The About Me section provides a brief yet insightful overview of my background, technical expertise, and passion for software development. It also highlights my experience in collaborative projects.

Visitors can even download my resume directly from the website, making it easy for recruiters and collaborators to connect with me.

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh
